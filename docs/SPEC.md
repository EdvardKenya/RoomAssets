# SPEC — Room & Assets

## Пользовательские истории

1. Видеть список аудиторий и инвентаря.
2. Искать ресурс по названию/инв. номеру.
3. Создавать бронь на аудиторию или единицу инвентаря на заданный интервал.
4. Получать ошибку и не иметь возможности сохранить бронь, если она
   пересекается по времени с уже существующей бронью того же ресурса.
5. Редактировать и удалять существующие брони.
6. Фильтровать брони по тексту, дате и ресурсу.
7. Экспортировать все данные в один JSON-файл и импортировать их обратно.

## Границы MVP

Входит: каталог ресурсов (просмотр + поиск), CRUD броней с проверкой
пересечений (проверяется и на клиенте для мгновенной подсказки, и на сервере
как источник истины), фильтры, импорт/экспорт, деплой фронтенда на GitHub
Pages и бэкенда на Render с автодеплоем из `main`.

Не входит: авторизация/многопользовательский режим, редактирование каталога
аудиторий/инвентаря через UI, повторяющиеся брони, персистентная БД (вместо
неё — JSON-файл на диске бэкенда).
