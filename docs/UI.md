# UI — экраны

## 1. Каталог ресурсов
Поиск + таблицы «Аудитории» и «Инвентарь» (данные приходят с `GET /api/rooms`,
`GET /api/assets`).

## 2. Брони
Фильтры (текст/дата/тип ресурса/ресурс), таблица броней, кнопка «Новая бронь».
Редактирование/удаление — иконки в строке.

## 3. Форма брони (модальное окно)
Тип ресурса → конкретный ресурс, название, начало/окончание, комментарий.
При конфликте бэкенд возвращает `409 { conflicts }}` — форма показывает ошибку
со списком конфликтующих броней и не закрывается, пока конфликт не устранён.

## Шапка
Вкладки навигации + «Экспорт»/«Импорт» (ходят на `/api/export` и `/api/import`).
